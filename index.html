Flujo del lector

1. Capturar o importar
La app puede recibir imágenes/PDF o usar la cámara experimental en vivo.
2. Separar páginas
Cada página queda como una hoja independiente del lote.
3. Detectar plantilla
Busca los cuatro cuadrados negros exteriores de tu plantilla actual.
4. Leer RUN y respuestas
Lee el RUN numérico y las burbujas A–D usando la geometría de tu hoja actual.
5. Revisar y guardar
Las anomalías se corrigen dentro de este mismo lote. Solo al pulsar “Guardar cambios” los resultados se traspasan al curso.
La v0.37.1 usa cámara a pantalla completa, contador de hojas y un flujo directo: capturar → cerrar y analizar OMR → revisar/guardar. El lector sigue amarrado a tu plantilla actual. En Revisión ahora puedes ver el recorte que leyó el algoritmo, confirmar/cambiar el estudiante, ingresar un RUN manual o corregir una respuesta ambigua.
