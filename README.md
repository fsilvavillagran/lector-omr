# Lector OMR Docente v0.43

Corrección posterior desde Resultados.

- La revisión manual ya no queda limitada al lote de escaneo.
- En Resultados aparece **Corregir respuestas**.
- Se puede cambiar cualquier respuesta guardada a A, B, C, D, E o Blanco.
- El puntaje, porcentaje, nota, habilidades, contenidos e informes se recalculan al guardar.
- Desde v0.43 se conserva también la hoja original en IndexedDB para revisarla después de limpiar el lote.
- Si existe la hoja original y la geometría guardada, la evidencia corregida se regenera después de una modificación.
- Los resultados anteriores a v0.43 siguen siendo editables; si no conservan hoja original, se usa como referencia la evidencia corregida disponible.
